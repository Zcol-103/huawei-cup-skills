# 华为杯评价类建模方法库

本 Skill 提炼自第二十届华为杯 39 篇优秀论文中实际出现的评价类方法，目标是让你在数模赛场上"看到评价题就知道用什么、怎么算、怎么写"。

## 1. 触发场景

- 题目要求"对 N 个方案/地区/医院/企业进行综合评价并排序"。
- 题目要求"建立评价指标体系，确定指标权重"。
- 题目要求"比较几种政策/技术/治疗方案的优劣"。
- 用户说"帮我做个 TOPSIS""用熵权法算权重""AHP 一致性检验不通过怎么办"。
- 用户已有指标数据，问"接下来怎么评价"。

## 2. 方法选择决策树

```
你手里有什么？
│
├─ 有专家经验/打分，但没多少数据？
│   ├─ 指标 ≤9 个，能两两比较 ──────► AHP / FAHP（methods/ahp.md）
│   ├─ 多轮专家咨询收敛 ────────────► 德尔菲法（methods/delphi.md）
│   └─ 专家意见分歧大 ──────────────► OWA 算子（D23104860011 用过）
│
├─ 有客观数据，想纯靠数据说话？
│   ├─ 指标变异性大、想区分度 ──────► 熵权法（methods/entropy-weight.md）
│   ├─ 指标间有冲突性 ──────────────► CRITIC 法（methods/critic.md）
│   └─ 指标太多想降维 ──────────────► PCA 主成分评价（methods/pca-evaluation.md）
│
├─ 主客观都要，显得更严谨？
│   └─ AHP+熵权 组合赋权 ──────────► 组合赋权（methods/combination-weight.md）
│       （乘法合成 / 博弈论 / 最小信息熵）
│
├─ 权重有了，怎么综合评分排序？
│   ├─ 各方案到最优/最劣的距离 ──────► TOPSIS（methods/topsis.md）
│   ├─ 样本少、数据灰度大 ──────────► 灰色关联（methods/grey-relational.md）
│   ├─ 指标有模糊性、评语集 ────────► 模糊综合评价（methods/fuzzy-evaluation.md）
│   └─ 既有最优距离又有关联度 ──────► 灰色关联-TOPSIS 组合
│
└─ 论文里怎么写才像获奖论文？
    └─ 8 步标准流程见 workflow.md
```

## 3. 高频方法在 39 篇论文中的出现频次

| 排名 | 方法 | 出现篇数 | 典型用途 |
|---|---|---|---|
| 1 | PCA 主成分 | ≥15 | 降维、指标筛选、综合得分 |
| 2 | 灰色关联 | 6 | 医疗题（E组）治疗方案与疗效关联分析 |
| 3 | 熵权法 | 6 | 客观赋权标配 |
| 4 | 德尔菲法 | 3 | 指标筛选、专家打分 |
| 5 | TOPSIS | 2 | 方案最终排序 |

| 7 | CRITIC | 1 | 与熵权对比 |
| 8 | 模糊综合 | 2 | 风险/质量分级 |

## 4. 来自获奖论文的经验法则

1. **单一方法容易被质疑**：获奖论文普遍"主观赋权 + 客观赋权"组合使用（AHP 给方向、熵权给精度）。
2. **必须做敏感性分析**：换权重、换归一化方法，看排名是否稳定。
3. **指标要分类型**：效益型（越大越好）、成本型（越小越好）、区间型（越接近某值越好），归一化公式不同。
4. **AHP 一致性检验不通过就重做判断矩阵**，不要硬上。
5. **样本量小（<10）别用复杂模型**，灰色关联 + 熵权-TOPSIS 足够。
6. **结果可视化**：权重用条形图、得分排序用条形图、雷达图做多维对比（配合 huawei-chart-style skill）。

## 6. 使用顺序

1. 读 `workflow.md` 了解 8 步标准流程。
2. 按决策树选 1-2 个方法，去 `methods/` 下读对应文档。
3. 复制代码模板，替换成你的数据。
4. 结果画图时调用 `huawei-chart-style` skill 的 04-评价与对比类文档。
