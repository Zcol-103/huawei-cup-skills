# 华为杯评价类建模方法 skill

本 skill 从 2022—2023 年用户提供的 100 篇论文中提炼“为什么这样组合、何时停止、如何面对新情况”的判断方法。论文证据、典型队号和禁用边界见 [references/2022-2023-corpus-insights.md](references/2022-2023-corpus-insights.md)。需要公式或代码时，再读取 `methods/`；需要完整写作清单时读取 [workflow.md](workflow.md)。

## 先判断是不是评价问题

明确四件事：评价对象（多个方案/地区/模型/等级）、决策目的（排序、分级、筛选、找短板）、时间范围、可接受的不确定性。若只有一个对象、没有备选方案，或任务本质是预测/因果/优化，不要硬套综合评价；评价最多作为后处理或模型比较层。

## 最小可辩护流程

1. **指标审计**：为每个指标写定义、单位、效益/成本/区间方向、来源和数据范围；检查缺失、异常、重复计量和共线。
2. **建模选择**：根据证据来源选一个主方法和一个必要的交叉验证方法，并写明不选其他方法的理由：
   - 专家判断、层级少 → AHP/FAHP/德尔菲；必须做一致性/收敛检查。
   - 数据离散度提供信息 → 熵权；指标冲突重要 → CRITIC。
   - 指标多且共线 → PCA/因子分析，但保留可解释载荷。
   - 样本少、信息不完全 → 灰色关联；语言等级/边界模糊 → 模糊综合。
   - 需要“接近最优/远离最劣”的排序 → TOPSIS；它不是权重来源，也不替代目标定义。
3. **保存中间量**：归一化矩阵、权重、理想解/关联度/隶属度、对象分数和等级阈值都可复核；防止只报最终名次。
4. **稳健性**：扰动权重、归一化、关键指标、时间窗口或样本后，报告 Spearman/Kendall、最大名次变化或等级转移；不稳定时报告不确定性，不强行给唯一冠军。
5. **解释与行动**：把“分数高/低”翻译成指标贡献、可干预因素和适用边界；区分相关性、测量评分和因果结论。

## 组合方法的克制规则

- 主观 + 客观不是默认正确，而是当专家知识与数据差异都不可忽略时的可检验假设；说明合成方式及其敏感性。
- 多方法串联只有每一环解决不同问题才成立；“AHP→熵权→TOPSIS→模糊”若没有信息增量，应删减。
- AHP 一致性不通过时重建判断矩阵或降级为客观方法，不能把不通过结果继续用于排名。
- 指标方向、归一化和阈值比算法名字更影响结果；任何改变都要在敏感性分析中显式记录。

## 论文级输出

交付评价模型时至少包含：对象与决策目的、指标表（方向/单位/来源）、数据审计、公式与假设、权重及检验、分数/排序/分级、稳健性结果、限制与行动建议，以及权重条形图和排序图。参照 `workflow.md` 和对应 `methods/*.md`，但允许在新题中偏离模板并解释原因。
