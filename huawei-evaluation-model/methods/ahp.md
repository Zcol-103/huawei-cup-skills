# AHP 层次分析法（含一致性检验）

## 适用场景

- 指标 ≤ 9 个，能两两比较。
- 有专家经验可以构造判断矩阵。
- 需要主观权重。
- 获奖案例：F23102520378（FAHP 模糊层次分析）、D23104860011。

## 步骤

1. 建立层次结构：目标层 → 准则层 → 指标层。
2. 构造两两比较判断矩阵 A（用 1-9 标度法）。
3. 求权重：特征向量法 / 几何平均法 / 求和法。
4. 一致性检验：算 CR，CR < 0.1 才通过。
5. 不通过就回去调整判断矩阵。

## 1-9 标度法

| 标度 | 含义 |
|---|---|
| 1 | 两因素同等重要 |
| 3 | 前者比后者稍重要 |
| 5 | 前者比后者明显重要 |
| 7 | 前者比后者强烈重要 |
| 9 | 前者比后者极端重要 |
| 2,4,6,8 | 中间值 |
| 倒数 | 反向比较 |

## 可运行代码

```python
import numpy as np
import pandas as pd

def ahp(A):
    """
    A: n×n 判断矩阵（二维 numpy 数组）
    返回: 权重 w, CR, 是否通过
    """
    n = len(A)
    # 几何平均法求权重
    w_geo = np.prod(A, axis=1) ** (1/n)
    w = w_geo / w_geo.sum()
    # 最大特征根
    lam_max = np.mean((A @ w) / w)
    # 一致性指标
    CI = (lam_max - n) / (n - 1)
    # 随机一致性指标 RI
    RI_table = {1:0, 2:0, 3:0.58, 4:0.90, 5:1.12,
                6:1.24, 7:1.32, 8:1.41, 9:1.46}
    RI = RI_table.get(n, 1.49)
    CR = CI / RI if RI > 0 else 0
    return w, CR, (CR < 0.1)

# 示例：6 个指标的判断矩阵
labels = ['经济', '社会', '环境', '成本', '能耗', '风险']
A = np.array([
    [1,   3,   5,   1/3, 3,   5  ],
    [1/3, 1,   3,   1/5, 1,   3  ],
    [1/5, 1/3, 1,   1/7, 1/3, 1  ],
    [3,   5,   7,   1,   5,   7  ],
    [1/3, 1,   3,   1/5, 1,   3  ],
    [1/5, 1/3, 1,   1/7, 1/3, 1  ],
])

w, cr, ok = ahp(A)
print("权重:")
for label, wi in zip(labels, w):
    print(f"  {label}: {wi:.4f}")
print(f"CR = {cr:.4f} -> {'通过 ✓' if ok else '不通过，需调整判断矩阵 ✗'}")
```

## 常见错误

1. **CR ≥ 0.1 还硬上**：必须回去改判断矩阵，不要在论文里写"CR=0.12 基本可接受"。
2. **判断矩阵不一致**：比如 A 比 B=3，B 比 C=3，那 A 比 C 应该是 9 左右，不能写成 1。
3. **指标 >9 个**：AHP 一致性很难过，改成分组 AHP 或用熵权。
4. **权重和不为 1**：最后一定要归一化。

## 与其他方法联用

- AHP 给主观权重 + 熵权给客观权重 → 组合赋权（见 combination-weight.md）。
- AHP 权重 × TOPSIS 距离 → FAHP-TOPSIS（F23102520378 用过）。
- 模糊 AHP（FAHP）：用三角模糊数代替 1-9 标度，适合不确定性大的场合。
