# 模糊综合评价

## 适用场景

- 评价结果是"优/良/中/差"这种模糊概念，不是精确数值。
- 指标有模糊性（如舒适度、满意度、风险等级）。
- 获奖案例：C23106130016、D23104860011。

## 步骤

1. 建立因素集 $U = \{u_1, u_2, ..., u_n\}$（评价指标）。
2. 建立评语集 $V = \{v_1, v_2, ..., v_m\}$（如优/良/中/差）。
3. 单因素模糊评价：得到模糊关系矩阵 $R$，$r_{ij}$ 表示 $u_i$ 被评为 $v_j$ 的隶属度。
4. 确定权重向量 $A$（用 AHP/熵权）。
5. 综合评价：$B = A \circ R$（模糊合成，常用加权平均型 $M(\cdot, +)$）。
6. 归一化 $B$，按最大隶属度原则或加权平均得分定级。

## 可运行代码

```python
import numpy as np
import pandas as pd

def fuzzy_eval(A, R, scores=None):
    """
    A: 权重向量 (n,)
    R: 模糊关系矩阵 (n, m)，每行和为1
    scores: 评语集对应分值 (m,)，如 [95,85,70,50]
    """
    # 加权平均型合成
    B = A @ R
    B = B / B.sum()
    if scores is None:
        # 默认按 1.0, 0.75, 0.5, 0.25 打分
        scores = np.linspace(1, 0, R.shape[1])
    total_score = B @ np.array(scores)
    return B, total_score

# 示例：3个指标，4个评语（优/良/中/差）
labels = ['优', '良', '中', '差']
scores = [95, 85, 70, 50]

# 权重（AHP 得到）
A = np.array([0.3, 0.4, 0.3])

# 模糊关系矩阵：每行是某指标被评为各等级的隶属度
R = np.array([
    [0.6, 0.3, 0.1, 0.0],   # 指标1
    [0.2, 0.5, 0.2, 0.1],   # 指标2
    [0.1, 0.3, 0.4, 0.2],   # 指标3
])

B, total = fuzzy_eval(A, R, scores)
print("综合隶属度：")
for l, b in zip(labels, B):
    print(f"  {l}: {b:.3f}")
print(f"综合得分：{total:.2f}")
print(f"评级：{labels[np.argmax(B)]}（最大隶属度原则）")
```

```
  差: 0.140

```

## 常见错误

1. **R 矩阵每行和不为 1**：要归一化隶属度。
2. **用 Zadeh 算子 $M(\vee, \wedge)$**：会丢失信息，推荐加权平均型 $M(\cdot, +)$。
3. **评语集太粗**：≤5 个等级，否则模糊性消失。
4. **最大隶属度原则失效**：若最大两个隶属度很接近，改用加权平均得分。

## 隶属度函数怎么取

- 专家打分统计：各专家投票比例直接作为隶属度。
- 三角形/梯形隶属函数：按指标数值区间分配。
- 指派方法：根据经验直接给 $r_{ij}$。
