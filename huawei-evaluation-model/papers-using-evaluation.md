## 四、方法选用建议

- **医疗/生命科学题（E 组风格）**：灰色关联 + CRITIC/熵权 是标配。
- **能源/环境题（D 组风格）**：熵权 + TOPSIS + 多情景分析。
- **评审/决策题（C 组风格）**：PCA 降维 + 回归/机器学习替代主观评价。
- **预报/工程题（F 组风格）**：FAHP+熵权+TOPSIS 评价模型好坏。
