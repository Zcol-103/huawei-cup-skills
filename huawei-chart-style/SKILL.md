# 华为杯优秀论文绘图风格

本 Skill 提炼自第二十届华为杯（中国研究生数学建模竞赛）C/D/E/F 四组共 39 篇优秀论文的真实配图规律，目标是让你画出"一眼像获奖论文"的图。

## 1. 触发场景

- 用户在写数模/研赛论文，需要配图、选图、调风格。
- 用户要求"华为杯风""研赛优秀论文风""学术论文 matplotlib 风""获奖论文配色"。
- 用户给了一组数据（时序、评分、特征重要性、相关矩阵、雷达对比、混淆矩阵、雷达回波），问"这数据该画什么图"。
- 用户已有图但嫌"丑/乱/土/不像论文"，要统一风格。

## 2. 全局一句话风格

> **白底、浅灰横纵网格线、中文宋体正文 + 英文 Times New Roman 坐标轴、主色蓝（#1f77b4 / #4472C4）、强调色橙（#ff7f0e / #ED7D31）或红（#C00000）、线宽 1.5、marker 8~10pt、DPI 300、图题居中于图下方。**

细节见 `charts/08-排版与配色规范.md`。所有代码模板顶部统一设置：

```python
import matplotlib.pyplot as plt
import matplotlib as mpl
# 中文字体：Windows 用 SimHei，Linux/Mac 用 Noto Sans CJK SC
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False   # 解决负号 - 显示为方块
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.edgecolor'] = '#333333'
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'
mpl.rcParams['grid.linewidth'] = 0.6
```

## 4. 选图决策树（什么场景选什么图）

```
你要表达什么？
│
├─ 数据分布（一个变量长什么样）？
│   ├─ 单变量分布形状 ───────────► 直方图 + KDE（01）
│   ├─ 多组分布对比/离群点 ──────► 箱线图（01）或 小提琴图（01）
│   └─ 占比构成（≤6 类）─────────► 饼图/环形图（01）
│
├─ 随时间/顺序变化的趋势？
│   ├─ 单一指标时序 ────────────► 折线图（02）
│   ├─ 绝对值 + 增长率 同时看 ──► 双轴柱线组合图（02，D 题标配）
│   ├─ 累积贡献/填充面积 ───────► 面积图（02）
│   └─ 真实值 vs 模型曲线 ──────► 拟合曲线图（02/06）
│
├─ 两个/多个变量之间的关系？
│   ├─ 两个连续变量 ────────────► 散点图（03）
│   ├─ 三个连续变量 + 类别 ──────► 3D 散点/气泡图（03）
│   ├─ 多个变量两两相关 ────────► 相关系数热力图（03）
│   └─ 多变量联合分布矩阵 ──────► 配对图 pairplot（03）
│
├─ 综合评价/方案对比/排名？
│   ├─ 多维度综合打分对比 ──────► 雷达图（04）
│   ├─ 单项指标排序/权重 ──────► 条形图（04）
│   ├─ TOPSIS/熵权得分排序 ─────► TOPSIS 排序条形图（04）
│   └─ 关键少数因素（80/20）────► 帕累托图（04）
│
├─ 空间/流向/网络关系？
│   ├─ 地理分布/雷达回波 ───────► 空间热力图（05，jet/viridis）
│   ├─ 来源→流向→去处 ─────────► 桑基图（05）
│   └─ 节点+连线关系 ───────────► 网络图（05）
│
├─ 模型效果/结果展示？
│   ├─ 线性/回归拟合好坏 ───────► 残差图（06）
│   ├─ 预测值 vs 真实值 ────────► 预测对比图（06）
│   ├─ 训练过程收敛 ────────────► 损失/MSE 收敛曲线（06）
│   ├─ 分类对错 ─────────────────► 混淆矩阵（06）
│   ├─ 二分类阈值综合表现 ──────► ROC 曲线（06）
│   └─ 参数影响排序 ────────────► 灵敏度龙卷风图（06）
│
└─ 方法/结构/路线说明？
    ├─ 全文/分问题思路 ─────────► 技术路线图（07，Visio 黑白框图）
    ├─ 算法步骤 ───────────────► 算法流程图（07）
```

## 5. 来自 39 篇论文的高频结论（直接照做）

1. **折线图、柱状图、流程图是三件套**，几乎每篇都有；先把这三类画规范。
2. **双轴柱线组合图**（左轴绝对值柱、右轴增长率线）是"现状分析"章节标配，红柱+蓝线或蓝柱+橙线。
3. **热力图**默认 `coolwarm`（相关系数）或 `magma`（医学特征）；空间雷达回波用 `jet` 或 `viridis`。
4. **流程图**别用 matplotlib 硬画，用 Visio/draw.io/PPT 画黑白或马卡龙色圆角矩形框图，导出 PNG 插入。
5. **中文坐标轴标注**比纯英文更常见（尤其 C/D/E 组），但图内小标签可英文。
6. **子图布局**偏爱 1×2 并排（a/b 对比）、2×2、2×3；同一组对比数据不要拆成两张独立图。
7. **DPI=300**，`bbox_inches='tight'`，避免坐标轴标签被裁。

## 6. 使用方式

1. 先读 `charts/08-排版与配色规范.md` 拿到全局 rcParams 和色板。
2. 按决策树找到对应类别文档，复制代码模板。
3. 模板里用 `numpy` 生成的是假数据，替换成你的真实数据即可。
4. 所有模板顶部已验证可在 Linux + matplotlib 3.11 / seaborn 0.13 跑通，输出 PNG 到 `/tmp/`。
