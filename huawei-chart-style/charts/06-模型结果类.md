# 06 模型结果类图表

> 用途：展示回归/分类/预测模型的拟合好坏、收敛过程、阈值表现、灵敏度。
> 论文中典型出现：残差分析、预测 vs 真实、训练损失下降、混淆矩阵、ROC、龙卷风图。

## 典型用途说明

| 图种 | 适用场景 | 论文中的典型问题 |
|---|---|---|
| 残差图 | 线性/回归模型假设检验 | 水肿进展拟合残差、回归拟合残差 |
| 预测对比图 | 时序/回归预测效果 | 真实值 vs 预测值折线 |
| 收敛/损失曲线 | 深度学习训练过程 | MSE/MAE 随 epoch 下降 |
| 混淆矩阵 | 分类模型对错 | 血肿扩张二分类、mRS 多分类 |
| ROC 曲线 | 二分类阈值综合表现 | AUC 对比 |
| 灵敏度龙卷风图 | 参数影响排序 | 各参数 ±x% 对输出影响 |

## 6.1 残差图

### 样式参数
- 残差 = 真实值 - 预测值
- 散点：绿色 `#2ca02c` 或蓝色 `#1f77b4`
- 零参考线：红色 `#C00000` 虚线
- x 轴为预测值或自变量，y 轴为残差

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

rng = np.random.default_rng(9)
x = np.sort(rng.uniform(0, 168, 100))
y_true = 5 + 0.08*x - 0.0012*x**2
y_pred = y_true + rng.normal(0, 1.2, len(x))     # 模拟预测
resid = y_true - y_pred

fig, ax = plt.subplots(figsize=(7.5, 4.5))
ax.scatter(y_pred, resid, color='#1f77b4', s=20, alpha=0.7, edgecolors='none')
ax.axhline(0, color='#C00000', linestyle='--', linewidth=1.2)
ax.set_xlabel('预测值（ml）')
ax.set_ylabel('残差（真实值 - 预测值）')
ax.set_title('拟合残差分布图', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/06_residual.png', dpi=300, bbox_inches='tight')
print('saved /tmp/06_residual.png')
```

### 常见坑
- 残差应随机分布在零线两侧；若呈喇叭形/弧形，说明模型有偏或异方差。
- 残差图要加零线，否则读者看不出偏差。

## 6.2 预测对比图（真实 vs 预测）

### 样式参数
- 真实值：黑色实线 `#333333`，linewidth=2
- 预测值：红色虚线 `#C00000` 或蓝色 `#1f77b4`，linewidth=1.8
- 历史段 vs 预测段用竖虚线分隔
- 预测区间：浅色填充 alpha=0.2

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

years = np.arange(2010, 2031)
rng = np.random.default_rng(4)
hist = 500 + 30*(years[:11]-2010) + rng.normal(0, 10, 11)
future = 500 + 30*(years[11:]-2010) - 5*np.arange(len(years)-11)   # 达峰后下降
predict = future + rng.normal(0, 15, len(future))

fig, ax = plt.subplots(figsize=(8, 4.5))
ax.plot(years[:11], hist, 'o-', color='#333333', linewidth=2, label='历史真实值')
ax.plot(years[11:], future, 's-', color='#C00000', linewidth=2, label='模型预测值')
ax.axvline(2020, color='#999999', linestyle='--', linewidth=1)
ax.text(2020.2, ax.get_ylim()[1]*0.9, '预测起点', color='#666666', fontsize=9)
ax.set_xlabel('年份')
ax.set_ylabel('碳排放量（万 tCO$_2$）')
ax.set_title('碳排放真实值与预测值对比', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/06_predict_compare.png', dpi=300, bbox_inches='tight')
print('saved /tmp/06_predict_compare.png')
```

## 6.3 收敛/损失曲线

### 样式参数
- 训练损失：深蓝 `#1f5fa8`，linewidth=1.8
- 验证损失：橙 `#ED7D31`，linewidth=1.8
- x 轴 epoch（对数坐标可选）
- 标记最优 epoch：竖虚线 + 文字

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

epochs = np.arange(1, 101)
train = 1.0*np.exp(-epochs/20) + 0.05 + np.random.default_rng(1).normal(0, 0.01, 100)
val = 1.0*np.exp(-epochs/25) + 0.15 + np.random.default_rng(2).normal(0, 0.02, 100)
best = np.argmin(val)

fig, ax = plt.subplots(figsize=(7.5, 4.5))
ax.plot(epochs, train, color='#1f5fa8', linewidth=1.8, label='训练损失')
ax.plot(epochs, val, color='#ED7D31', linewidth=1.8, label='验证损失')
ax.axvline(epochs[best], color='#C00000', linestyle='--', linewidth=1)
ax.text(epochs[best]+1, ax.get_ylim()[1]*0.8, f'最优 epoch={epochs[best]}',
        color='#C00000', fontsize=9)
ax.set_xlabel('训练轮次 epoch')
ax.set_ylabel('MSE 损失')
ax.set_title('模型训练收敛曲线', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/06_loss_curve.png', dpi=300, bbox_inches='tight')
print('saved /tmp/06_loss_curve.png')
```

## 6.4 混淆矩阵

### 样式参数
- 蓝橙双色：正确类（对角）深蓝 `#2E75B6`，错误类浅橙 `#F4B183`
- 白色数字标注样本数
- 横纵轴标签为类别名（真实 / 预测）
- 用 seaborn heatmap 实现

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10

cm = np.array([[85, 8],
               [10, 57]])
classes = ['未扩张', '扩张']

fig, ax = plt.subplots(figsize=(5.5, 4.8))
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues', cbar=False,
            xticklabels=classes, yticklabels=classes, ax=ax,
            annot_kws={'size': 14, 'color': 'white'},
            linewidths=1, linecolor='white')
ax.set_xlabel('预测类别')
ax.set_ylabel('真实类别')
ax.set_title('混淆矩阵', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/06_confusion_matrix.png', dpi=300, bbox_inches='tight')
print('saved /tmp/06_confusion_matrix.png')
```

### 常见坑
- 多分类（>2 类）时不要全用同色，用 Blues 渐变即可。
- 数字颜色与背景对比：深色底用白字，浅色底用黑字。

## 6.5 ROC 曲线

### 样式参数
- 随机参考线：黑色虚线 y=x
- 多模型用不同颜色：`#1f77b4`、`#ff7f0e`、`#2ca02c`、`#d62728`
- 图例标注 AUC 值：`XGBoost (AUC=0.94)`
- x 轴 FPR，y 轴 TPR，范围 0~1

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

# 模拟 ROC 点
def roc_curve(auc):
    fpr = np.linspace(0, 1, 100)
    tpr = 1 - (1-fpr)**(1/(1-auc+0.001))
    return fpr, np.clip(tpr, 0, 1)

models = [('XGBoost', 0.94, '#1f77b4'),
          ('随机森林', 0.88, '#ff7f0e'),
          ('LightGBM', 0.91, '#2ca02c'),
          ('逻辑回归', 0.82, '#d62728')]

fig, ax = plt.subplots(figsize=(6.5, 6))
ax.plot([0, 1], [0, 1], 'k--', linewidth=1, label='随机分类器')
for name, auc, c in models:
    fpr, tpr = roc_curve(auc)
    ax.plot(fpr, tpr, color=c, linewidth=2, label=f'{name} (AUC={auc:.2f})')
ax.set_xlabel('假正率 FPR')
ax.set_ylabel('真正率 TPR')
ax.set_title('四个二分类模型 ROC 曲线对比', fontsize=12)
ax.legend(frameon=False, loc='lower right')
ax.set_xlim(0, 1); ax.set_ylim(0, 1.02)
plt.tight_layout()
plt.savefig('/tmp/06_roc.png', dpi=300, bbox_inches='tight')
print('saved /tmp/06_roc.png')
```

## 6.6 灵敏度龙卷风图

### 样式参数
- 横向条形图，每个参数有左右两根（-x% / +x% 对输出的影响）
- 蓝色表示负向，红色表示正向，或同色深浅
- 按影响幅度从大到小排序（形成龙卷风形状）
- 中间竖线为基准输出

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

params = ['能源强度', '产业结构', '人口', '能源结构', '技术进步']
low =  [-12, -8, -5, -4, -2]    # -10% 时输出变化（%）
high = [ 10,  7,  4,  3,  1]    # +10% 时输出变化（%）
order = np.argsort([abs(l)+abs(h) for l, h in zip(low, high)])
params_s = [params[i] for i in order]
low_s = [low[i] for i in order]
high_s = [high[i] for i in order]

y = np.arange(len(params_s))
fig, ax = plt.subplots(figsize=(7.5, 4.5))
ax.barh(y, low_s, color='#4472C4', alpha=0.8, label='参数 -10%')
ax.barh(y, high_s, color='#C00000', alpha=0.8, label='参数 +10%')
ax.set_yticks(y); ax.set_yticklabels(params_s)
ax.axvline(0, color='#333333', linewidth=1)
ax.set_xlabel('输出变化（%）')
ax.set_title('碳排放预测模型参数灵敏度龙卷风图', fontsize=12)
ax.legend(frameon=False, loc='lower right')
plt.tight_layout()
plt.savefig('/tmp/06_tornado.png', dpi=300, bbox_inches='tight')
print('saved /tmp/06_tornado.png')
```

### 避坑总建议
- 残差图、预测对比图是回归论文标配，至少各一张。
- ROC 曲线必须画随机参考线（y=x），否则 AUC 无意义。
- 混淆矩阵数字标注要清晰，多分类时热力图色阶不要太艳。
