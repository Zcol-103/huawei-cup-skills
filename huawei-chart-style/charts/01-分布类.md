# 01 分布类图表

> 用途：展示一个或多个变量的取值分布形状、集中趋势、离群点、占比构成。
> 论文中典型出现：专家评分分布、成绩分布、变量取值分布、簇占比、治疗方法占比。

## 典型用途说明

| 图种 | 适用场景 | 论文中的典型问题 |
|---|---|---|
| 直方图 + KDE | 单变量是否近似正态、取值集中在哪里 | 专家打分分布、水肿体积分布、预测值分布 |
| 箱线图 | 多组数据五数概括、离群点对比 | 不同治疗方式对血肿体积影响、各特征离群值 |
| 小提琴图 | 多组分布形状 + 密度 | 两阶段标准分极差分布对比 |
| 核密度图 (KDE + rug) | 平滑分布、尾部行为 | 成绩概率密度、核密度估计 |
| 饼图/环形图 | 类别占比（≤6 类） | 获奖比例、簇占比、性别分布、碳排放结构 |

## 1.1 直方图 + KDE

### 样式参数
- 柱色：`#4472C4`（蓝）或 `#4ECDC4`（青绿），alpha=0.6
- KDE 曲线：同色加深，linewidth=2
- 网格：仅 y 轴浅灰横线
- 子图：多变量时用 2×2 或 2×3

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'
mpl.rcParams['grid.linewidth'] = 0.6

from scipy.stats import gaussian_kde

rng = np.random.default_rng(42)
data1 = rng.normal(loc=75, scale=8, size=300)   # 专家 A 打分
data2 = rng.normal(loc=82, scale=6, size=300)   # 专家 B 打分

fig, ax = plt.subplots(figsize=(7, 4.5))
# 直方图
ax.hist(data1, bins=25, density=True, alpha=0.55, color='#4472C4', label='专家 P090')
ax.hist(data2, bins=25, density=True, alpha=0.55, color='#ED7D31', label='专家 P112')
# KDE 曲线
for d, c in [(data1, '#1f5fa8'), (data2, '#c55a11')]:
    kde = gaussian_kde(d)
    xs = np.linspace(d.min()-5, d.max()+5, 200)
    ax.plot(xs, kde(xs), color=c, linewidth=2)
ax.set_xlabel('评分')
ax.set_ylabel('概率密度')
ax.set_title('专家评分分布直方图与 KDE 曲线', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/01_hist_kde.png', dpi=300, bbox_inches='tight')
print('saved /tmp/01_hist_kde.png')
```

### 常见坑
- 直方图 bins 默认 10 太粗，评分类数据用 25~30 个 bin。
- 叠加两组时务必 `density=True` 且 alpha<0.6，否则互相遮挡。
- KDE 要画在直方图上方，先 hist 后 plot。

## 1.2 箱线图

### 样式参数
- 箱体：蓝色 `#4472C4`，alpha=0.5
- 中位数线：`#C00000`（红），linewidth=2
- 离群点：蓝色小圆点，marker='o', markersize=3
- 横向箱线图用 `vert=False`，适合类别名长时

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

rng = np.random.default_rng(7)
groups = ['第一组', '第二组', '第三组', '第四组', '第五组']
data = [rng.normal(loc=70+i*3, scale=6+i*1.5, size=120) for i in range(5)]

fig, ax = plt.subplots(figsize=(7, 4.5))
bp = ax.boxplot(data, tick_labels=groups, patch_artist=True, widths=0.55,
                medianprops={'color': '#C00000', 'linewidth': 2},
                flierprops={'marker': 'o', 'markerfacecolor': '#4472C4',
                            'markeredgecolor': '#4472C4', 'markersize': 3})
for patch in bp['boxes']:
    patch.set_facecolor('#4472C4')
    patch.set_alpha(0.5)
ax.set_ylabel('标准分')
ax.set_title('五组评审标准分箱线图', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/01_box.png', dpi=300, bbox_inches='tight')
print('saved /tmp/01_box.png')
```

### 常见坑
- `patch_artist=True` 才能给箱体填色；默认中空。
- 类别名长时改横向：`boxplot(..., vert=False)` 并把 y 轴当类别轴。
- 离群点太多说明数据本身偏态，先考虑小提琴图。

## 1.3 小提琴图

### 样式参数
- 多组配色：`#5B9BD5`（蓝）、`#48D1CC`（青）、`#70AD47`（绿）
- 内部显示箱线：`inner='box'`
- linewidth=1.2

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11

rng = np.random.default_rng(11)
groups = ['第一阶段', '第二阶段']
data = np.concatenate([rng.normal(0.3, 0.2, 200), rng.normal(0.5, 0.3, 200)])
labels = np.array(['第一阶段']*200 + ['第二阶段']*200)

fig, ax = plt.subplots(figsize=(6.5, 4.5))
sns.violinplot(x=labels, y=data, ax=ax,
               palette={'第一阶段': '#5B9BD5', '第二阶段': '#48D1CC'},
               inner='box', linewidth=1.2)
ax.set_xlabel('评审阶段')
ax.set_ylabel('极差')
ax.set_title('两阶段评审极差小提琴图', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/01_violin.png', dpi=300, bbox_inches='tight')
print('saved /tmp/01_violin.png')
```

### 常见坑
- seaborn 的 violinplot 传入 Series+DataFrame 更方便；纯 numpy 时手动拼 labels。
- `inner='box'` 显示内嵌箱线，`inner='quartile'` 只画四分位线。

## 1.4 核密度图 + rug

### 样式参数
- 多组颜色：蓝 `#1f77b4`、红 `#C00000`、灰 `#7F7F7F`、橙 `#ED7D31`
- fill alpha=0.25
- rug：底部短竖线，颜色与曲线同

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11

rng = np.random.default_rng(3)
a = rng.normal(70, 8, 250)
b = rng.normal(78, 10, 250)

fig, ax = plt.subplots(figsize=(7, 4.5))
sns.kdeplot(x=a, ax=ax, color='#1f77b4', fill=True, alpha=0.25, linewidth=2, label='方案一')
sns.kdeplot(x=b, ax=ax, color='#C00000', fill=True, alpha=0.25, linewidth=2, label='方案二')
# rug 须线
sns.rugplot(x=a, ax=ax, color='#1f77b4', height=0.05)
sns.rugplot(x=b, ax=ax, color='#C00000', height=0.05)
ax.set_xlabel('成绩')
ax.set_ylabel('概率密度')
ax.set_title('两种评审方案成绩核密度估计', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/01_kde_rug.png', dpi=300, bbox_inches='tight')
print('saved /tmp/01_kde_rug.png')
```

## 1.5 饼图 / 环形图

### 样式参数
- 标准四色：`#C00000`（红）、`#2E75B6`（深蓝）、`#F4B183`（粉橙）、`#A9D18E`（灰蓝绿）
- 环形图：`wedgeprops={'width': 0.4}`
- 百分比标注：`autopct='%.1f%%'`
- 不要超过 6 类，其余归为"其他"

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11

labels = ['一等奖', '二等奖', '三等奖', '未获奖']
sizes = [8, 27, 45, 20]
colors = ['#C00000', '#2E75B6', '#F4B183', '#A9D18E']

fig, axes = plt.subplots(1, 2, figsize=(10, 4.5))
# 普通饼图
axes[0].pie(sizes, labels=labels, colors=colors, autopct='%.1f%%',
            startangle=90, textprops={'fontsize': 10})
axes[0].set_title('获奖比例饼图', fontsize=12)
# 环形图（甜甜圈）
axes[1].pie(sizes, labels=labels, colors=colors, autopct='%.1f%%',
            startangle=90, wedgeprops={'width': 0.4, 'edgecolor': 'white'},
            textprops={'fontsize': 10})
axes[1].set_title('获奖比例环形图', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/01_pie.png', dpi=300, bbox_inches='tight')
print('saved /tmp/01_pie.png')
```

### 常见坑
- 饼图类别 >6 时视觉灾难，合并小类为"其他"。
- 论文里饼图偶尔被批"不科学"，优先用条形图；但簇占比、构成分析用饼图仍常见。
- 起始角 `startangle=90` 让第一块从正上方开始，更整齐。

### 避坑总建议
- 分布类图别用 seaborn 默认深色背景，坚持白底 + 浅灰网格。
- 多组对比优先小提琴图（能看形状），箱线图仅用于强调离群点和中位数。
- 中文类别名用 4~6 字简称，过长时改用横向箱线图。
