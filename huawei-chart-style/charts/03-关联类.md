# 03 关联类图表

> 用途：展示变量之间的相关、聚类、联合分布关系。
> 论文中典型出现：专家-作品打分散点、相关系数矩阵、t-SNE 降维聚类、ZH-ZDR-R 关系、pairplot。

## 典型用途说明

| 图种 | 适用场景 | 论文中的典型问题 |
|---|---|---|
| 二维散点图 | 两个连续变量关系、加 y=x 参考线 | 原始分 vs 标准分、预测 vs 真实 |
| 3D/气泡散点 | 三个连续变量 + 类别/大小 | 专家×作品×分数、ZH×ZDR×降水 |
| 聚类散点 | 多簇分类着色 | K-means/t-SNE 聚类结果 |
| 热力图（相关矩阵） | 多变量相关系数 | Pearson/Spearman 相关矩阵 |
| 配对散点矩阵 pairplot | 多变量两两联合分布 | 人口-GDP-碳排放联合分布 |

## 3.1 二维散点图（含 y=x 参考线）

### 样式参数
- 散点：蓝色 `#1f77b4`，s=15，alpha=0.6，edgecolors='none'
- 参考线：黑色虚线 `#333333`，linestyle='--'，linewidth=1
- 回归线：红色 `#C00000`，linewidth=1.5
- 聚类散点：每簇一种色，tab10 六色

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

rng = np.random.default_rng(21)
x = rng.normal(0, 1, 200)
y = 0.85*x + rng.normal(0, 0.4, 200)   # 第二次评审 vs 第一次

fig, ax = plt.subplots(figsize=(6.5, 6))
ax.scatter(x, y, color='#1f77b4', s=18, alpha=0.6, edgecolors='none', label='样本')
lims = [min(x.min(), y.min())-0.5, max(x.max(), y.max())+0.5]
ax.plot(lims, lims, 'k--', linewidth=1, label='y=x 参考线')
# 线性拟合
coef = np.polyfit(x, y, 1)
xs = np.linspace(lims[0], lims[1], 100)
ax.plot(xs, np.polyval(coef, xs), color='#C00000', linewidth=1.5,
        label=f'拟合线 y={coef[0]:.2f}x+{coef[1]:.2f}')
ax.set_xlim(lims); ax.set_ylim(lims)
ax.set_xlabel('第一次评审标准分')
ax.set_ylabel('第二次评审标准分')
ax.set_title('两次评审标准分一致性散点图', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/03_scatter_identity.png', dpi=300, bbox_inches='tight')
print('saved /tmp/03_scatter_identity.png')
```

### 常见坑
- 点太多（>1000）时 alpha=0.4 并去掉 edgecolors，否则糊成一团。
- y=x 参考线必须等坐标轴比例 `ax.set_aspect('equal')` 才真正 45°。

## 3.2 聚类散点图（多簇着色）

### 样式参数
- 六色：`#1f77b4` 蓝、`#ff7f0e` 橙、`#2ca02c` 绿、`#d62728` 红、`#9467bd` 紫、`#8c564b` 棕
- 每簇 marker 形状可不同：o / s / ^ / D / x
- 簇心：黑色大空心圈，s=120, facecolors='none', edgecolors='k'

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

from sklearn.datasets import make_blobs
X, y = make_blobs(n_samples=300, centers=3, n_features=2,
                  cluster_std=0.8, random_state=42)
colors = ['#1f77b4', '#ff7f0e', '#2ca02c']
markers = ['o', 's', '^']

fig, ax = plt.subplots(figsize=(7, 5))
for k in range(3):
    mask = y == k
    ax.scatter(X[mask, 0], X[mask, 1], c=colors[k], marker=markers[k],
               s=30, alpha=0.7, edgecolors='none', label=f'簇 {k+1}')
    center = X[mask].mean(axis=0)
    ax.scatter(center[0], center[1], s=180, facecolors='none',
               edgecolors='k', linewidths=1.5)
ax.set_xlabel('特征 1（均值）')
ax.set_ylabel('特征 2（标准差）')
ax.set_title('K-means 聚类结果散点图', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/03_cluster_scatter.png', dpi=300, bbox_inches='tight')
print('saved /tmp/03_cluster_scatter.png')
```

## 3.3 3D 散点图

### 样式参数
- viridis 色阶：`#440154`→`#3b528b`→`#21918c`→`#5ec962`→`#fde725`
- 或每簇单色（C 组 MATLAB 蓝色点云 `#0072BD`）
- view_init(elev=20, azim=135) 固定视角
- 浅灰 pane 背景

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11

rng = np.random.default_rng(8)
n = 400
expert = rng.integers(0, 125, n)
work = rng.integers(0, 3000, n)
score = rng.normal(75, 10, n)

fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection='3d')
sc = ax.scatter(expert, work, score, c=score, cmap='viridis', s=8, alpha=0.7)
ax.set_xlabel('专家编号', labelpad=8)
ax.set_ylabel('作品编号', labelpad=8)
ax.set_zlabel('原始分数', labelpad=8)
ax.view_init(elev=20, azim=135)
ax.set_title('专家-作品-原始分数三维散点图', fontsize=12)
plt.colorbar(sc, ax=ax, shrink=0.6, label='分数')
plt.tight_layout()
plt.savefig('/tmp/03_3d_scatter.png', dpi=300, bbox_inches='tight')
print('saved /tmp/03_3d_scatter.png')
```

### 常见坑
- 3D 图点过密（>3000）会变成实心球云，先用 viridis 着色区分强度。
- labelpad=8 避免轴标签被 tick 遮挡。

## 3.4 相关系数热力图

### 样式参数
- diverging 色板：`coolwarm`（蓝负-白零-红正）或 `RdBu_r`
- 取值范围：vmin=-1, vmax=1, center=0
- 单元格标注数值：annot=True, fmt='.2f'
- 变量名用中文或缩写，字号小（8~9）

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10

rng = np.random.default_rng(14)
cols = ['GDP', '人口', '能耗', '碳排放', '新能源', '城镇化率']
data = rng.normal(0, 1, (100, 6))
corr = np.corrcoef(data.T)
# 强制一些相关让图好看
corr[0, 3] = corr[3, 0] = 0.85
corr[2, 3] = corr[3, 2] = 0.72
corr[4, 3] = corr[3, 4] = -0.45

fig, ax = plt.subplots(figsize=(7, 6))
sns.heatmap(corr, ax=ax, annot=True, fmt='.2f', cmap='coolwarm',
            vmin=-1, vmax=1, center=0, square=True,
            xticklabels=cols, yticklabels=cols,
            cbar_kws={'shrink': 0.8},
            annot_kws={'size': 9})
ax.set_title('变量 Pearson 相关系数热力图', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/03_heatmap_corr.png', dpi=300, bbox_inches='tight')
print('saved /tmp/03_heatmap_corr.png')
```

### 常见坑
- 相关矩阵必须对称（np.corrcoef 已保证）；非对称矩阵别用 coolwarm。
- 变量 >15 个时去掉 annot（文字重叠），只保留色阶。
- `square=True` 让每个格子正方形，更整齐。

## 3.5 配对散点矩阵（pairplot）

### 样式参数
- 对角：直方图或 KDE
- 非对角：散点
- 按类别着色：hue 参数

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 9

rng = np.random.default_rng(33)
df = pd.DataFrame({
    'GDP': rng.normal(100, 20, 80),
    '人口': rng.normal(5000, 800, 80),
    '能耗': rng.normal(300, 60, 80),
    '类别': rng.choice(['第一产业', '第二产业', '第三产业'], 80)
})
g = sns.pairplot(df, hue='类别', diag_kind='kde',
                 palette={'第一产业': '#1f77b4', '第二产业': '#d62728', '第三产业': '#2ca02c'},
                 plot_kws={'s': 18, 'alpha': 0.7})
g.fig.suptitle('多变量配对散点矩阵', y=1.02, fontsize=12)
plt.savefig('/tmp/03_pairplot.png', dpi=300, bbox_inches='tight')
print('saved /tmp/03_pairplot.png')
```

### 常见坑
- pairplot 变量 >5 个时矩阵太大，只选核心 3~4 个变量。
- 无类别时去掉 hue，对角线统一用 'hist' 或 'kde'。

### 避坑总建议
- 散点图永远加 edgecolors='none'，否则点边重叠显脏。
- 相关矩阵色板固定 coolwarm，别用 jet（被学术圈批评）。
- 3D 散点仅在第三维确实有信息时用，否则退化成 2D。
