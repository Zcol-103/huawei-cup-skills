# 07 流程与示意类图表

> 用途：展示技术路线、算法步骤、深度网络结构、物理/医学结构示意。
> 论文中典型出现：全文技术路线图（39/39 篇全部）、各小问流程图、U-Net/ConvLSTM 网络架构、算法步骤图。

## 典型用途说明

| 图种 | 适用场景 | 论文中的典型问题 |
|---|---|---|
| 技术路线图 | 全文/分问题思路总览 | 第二章开篇总体框架 |
| 算法流程图 | 具体算法步骤（含判断分支） | NSGA-II、K-means、XGBoost 流程 |
| 网络结构框图 | 深度学习模型架构 | U-Net、ConvLSTM、GAN、扩散模型 |
| 结构示意/医学示意图 | 物理/医学背景解释 | 出血性脑卒中位置、雨滴形状 |

## 重要：流程图不要硬用 matplotlib 画

**强烈建议**：技术路线图、算法流程图、网络结构图用 **Visio / draw.io / PPT / PowerPoint** 手绘，导出 PNG（DPI=300）后插入论文。原因：
- matplotlib 画方框+箭头定位痛苦，调整一次要改代码。
- 获奖论文的流程图 90% 是 Visio/draw.io 风格，不是 matplotlib 生成。
- 手绘能自由调整布局、颜色、对齐。

但本 Skill 仍提供 matplotlib 模板，用于快速原型和网络结构示意图。

## 7.1 技术路线图（matplotlib 原型）

### 样式参数
- 圆角矩形：boxstyle='round,pad=0.5'
- 马卡龙色：浅粉 #FCE4D6、浅紫 #E4DFEC、浅蓝 #D6E4F0、浅绿 #E2EFDA、浅黄 #FFF2CC
- 连接箭头：灰色 #7F7F7F，arrowstyle='->'
- 字体：中文 11pt

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import matplotlib.pyplot as plt
from matplotlib.patches import FancyBboxPatch, FancyArrowPatch
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10

fig, ax = plt.subplots(figsize=(11, 5.5))
ax.set_xlim(0, 11); ax.set_ylim(0, 5.5); ax.axis('off')

# 定义节点：(x, y, w, h, 文字, 填充色)
nodes = [
    (0.3, 2.2, 1.6, 1.0, '数据预处理\n与清洗', '#D6E4F0'),
    (2.3, 2.2, 1.6, 1.0, '指标体系\n构建', '#E2EFDA'),
    (4.3, 2.2, 1.6, 1.0, '问题一\n交叉分发模型', '#FCE4D6'),
    (6.3, 3.6, 1.6, 1.0, '问题二\n标准分修正', '#FFF2CC'),
    (6.3, 0.8, 1.6, 1.0, '问题三\n极差模型', '#FFF2CC'),
    (8.3, 2.2, 1.6, 1.0, '问题四\n全流程优化', '#E4DFEC'),
]
for x, y, w, h, text, color in nodes:
    box = FancyBboxPatch((x, y), w, h, boxstyle='round,pad=0.08',
                         linewidth=1.2, edgecolor='#7F7F7F', facecolor=color)
    ax.add_patch(box)
    ax.text(x+w/2, y+h/2, text, ha='center', va='center', fontsize=10)

# 箭头
arrows = [
    (1.9, 2.7, 2.3, 2.7),
    (3.9, 2.7, 4.3, 2.7),
    (5.9, 2.9, 6.3, 3.9),
    (5.9, 2.5, 6.3, 1.3),
    (7.9, 4.1, 8.3, 2.9),
    (7.9, 1.3, 8.3, 2.3),
]
for x1, y1, x2, y2 in arrows:
    ax.add_patch(FancyArrowPatch((x1, y1), (x2, y2),
                                 arrowstyle='->', mutation_scale=15,
                                 color='#7F7F7F', linewidth=1.2))
ax.set_title('总体技术路线图（matplotlib 原型，建议用 Visio/draw.io 重绘）', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/07_tech_route.png', dpi=300, bbox_inches='tight')
print('saved /tmp/07_tech_route.png')
```

## 7.2 算法流程图（含判断分支）

### 样式参数
- 矩形：处理步骤，浅蓝 #D6E4F0
- 菱形：判断，浅黄 #FFF2CC
- 起止：椭圆，浅绿 #E2EFDA
- 箭头：灰色

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import matplotlib.pyplot as plt
from matplotlib.patches import FancyBboxPatch, Polygon, FancyArrowPatch
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10

fig, ax = plt.subplots(figsize=(7, 7))
ax.set_xlim(0, 7); ax.set_ylim(0, 7); ax.axis('off')

# 起止椭圆
ax.add_patch(FancyBboxPatch((2.5, 6.2), 2, 0.6, boxstyle='round,pad=0.3',
                             facecolor='#E2EFDA', edgecolor='#7F7F7F'))
ax.text(3.5, 6.5, '开始', ha='center', va='center')
# 处理 1
ax.add_patch(FancyBboxPatch((2.5, 5.0), 2, 0.7, boxstyle='round,pad=0.05',
                             facecolor='#D6E4F0', edgecolor='#7F7F7F'))
ax.text(3.5, 5.35, '输入数据', ha='center', va='center')
# 判断菱形
diamond = Polygon([(3.5, 4.5), (4.8, 3.8), (3.5, 3.1), (2.2, 3.8)],
                  facecolor='#FFF2CC', edgecolor='#7F7F7F')
ax.add_patch(diamond)
ax.text(3.5, 3.8, '收敛?', ha='center', va='center')
# 是 → 输出
ax.add_patch(FancyBboxPatch((5.2, 3.5), 1.5, 0.6, boxstyle='round,pad=0.05',
                             facecolor='#D6E4F0', edgecolor='#7F7F7F'))
ax.text(5.95, 3.8, '输出结果', ha='center', va='center', fontsize=9)
# 否 → 更新参数
ax.add_patch(FancyBboxPatch((2.5, 2.0), 2, 0.7, boxstyle='round,pad=0.05',
                             facecolor='#D6E4F0', edgecolor='#7F7F7F'))
ax.text(3.5, 2.35, '更新参数', ha='center', va='center')
# 结束
ax.add_patch(FancyBboxPatch((2.5, 0.6), 2, 0.6, boxstyle='round,pad=0.3',
                             facecolor='#E2EFDA', edgecolor='#7F7F7F'))
ax.text(3.5, 0.9, '结束', ha='center', va='center')

# 箭头
def arrow(p1, p2):
    ax.add_patch(FancyArrowPatch(p1, p2, arrowstyle='->',
                                 mutation_scale=14, color='#7F7F7F'))
arrow((3.5, 6.2), (3.5, 5.7))
arrow((3.5, 5.0), (3.5, 4.5))
arrow((4.8, 3.8), (5.2, 3.8))     # 是
arrow((3.5, 3.1), (3.5, 2.7))     # 否
arrow((3.5, 2.0), (3.5, 1.2))
ax.text(4.2, 4.0, '是', fontsize=9, color='#C00000')
ax.text(3.6, 3.3, '否', fontsize=9, color='#C00000')
ax.set_title('算法流程图（原型，建议 draw.io 重绘）', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/07_algorithm_flow.png', dpi=300, bbox_inches='tight')
print('saved /tmp/07_algorithm_flow.png')
```

## 7.3 深度网络结构示意图（U-Net 风格）

### 样式参数
- 编码器块：蓝色 #4472C4，逐步缩小
- 解码器块：绿色 #70AD47，逐步放大
- 跳跃连接：红色粗箭头 #C00000
- 池化：红色向下箭头；上采样：绿色向上箭头
- 标注通道数（64/128/256/512）

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import matplotlib.pyplot as plt
from matplotlib.patches import FancyBboxPatch, FancyArrowPatch
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 9

fig, ax = plt.subplots(figsize=(11, 4.5))
ax.set_xlim(0, 11); ax.set_ylim(0, 4.5); ax.axis('off')

# 编码器（左→右缩小）
enc = [(0.3, 2.5, 1.2, 1.2, 'Conv\n64', '#4472C4'),
       (2.0, 2.7, 1.0, 1.0, 'Conv\n128', '#4472C4'),
       (3.5, 2.9, 0.8, 0.8, 'Conv\n256', '#4472C4'),
       (4.8, 3.0, 0.6, 0.6, 'Conv\n512', '#4472C4')]
for x, y, w, h, t, c in enc:
    ax.add_patch(FancyBboxPatch((x, y), w, h, boxstyle='round,pad=0.03',
                                 facecolor=c, edgecolor='white', alpha=0.9))
    ax.text(x+w/2, y+h/2, t, ha='center', va='center', color='white', fontsize=8)

# 解码器（右→左放大，下排）
dec = [(6.0, 0.8, 0.6, 0.6, 'Up\n512', '#70AD47'),
       (7.0, 0.9, 0.8, 0.8, 'Up\n256', '#70AD47'),
       (8.2, 1.0, 1.0, 1.0, 'Up\n128', '#70AD47'),
       (9.5, 1.1, 1.2, 1.2, 'Up\n64', '#70AD47')]
for x, y, w, h, t, c in dec:
    ax.add_patch(FancyBboxPatch((x, y), w, h, boxstyle='round,pad=0.03',
                                 facecolor=c, edgecolor='white', alpha=0.9))
    ax.text(x+w/2, y+h/2, t, ha='center', va='center', color='white', fontsize=8)

# 跳跃连接（红色粗箭头，从编码器到对应解码器）
skip = [(1.5, 3.1, 9.5, 2.0),
        (3.0, 3.2, 8.2, 2.0),
        (4.3, 3.2, 7.0, 1.7)]
for x1, y1, x2, y2 in skip:
    ax.add_patch(FancyArrowPatch((x1, y1), (x2, y2),
                                 arrowstyle='->', mutation_scale=12,
                                 color='#C00000', linewidth=1.5,
                                 connectionstyle='arc3,rad=0.1'))
# 下采样箭头
for x1, x2 in [(1.5, 2.0), (3.0, 3.5), (4.3, 4.8)]:
    ax.add_patch(FancyArrowPatch((x1, 3.1), (x2, 3.1),
                                 arrowstyle='->', mutation_scale=12,
                                 color='#333333', linewidth=1))
# 上采样箭头
for x1, x2 in [(5.4, 6.0), (6.6, 7.0), (7.8, 8.2)]:
    ax.add_patch(FancyArrowPatch((x1, 1.4), (x2, 1.4),
                                 arrowstyle='->', mutation_scale=12,
                                 color='#333333', linewidth=1))
ax.set_title('U-Net 网络结构示意图（原型，建议 draw.io/PowerPoint 重绘）', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/07_unet.png', dpi=300, bbox_inches='tight')
print('saved /tmp/07_unet.png')
```

### 避坑总建议
- 流程图优先 Visio/draw.io/PPT，matplotlib 只用于快速原型。
- 马卡龙色（浅粉/紫/蓝/绿/黄）是 D 组技术路线图标准配色，比黑白框图更"获奖相"。
- 网络结构图用彩色模块 + 红色跳跃连接箭头，通道数标注在块内。
- 流程图导出时 DPI=300，背景白色，不要阴影效果。
