# 02 趋势类图表

> 用途：展示随时间/顺序变化的指标走势、增长率、模型拟合曲线、面积累积。
> 论文中典型出现：碳排放/GDP 时序、CSI/准确率随预测步长、训练损失下降、真实值 vs 拟合值。

## 典型用途说明

| 图种 | 适用场景 | 论文中的典型问题 |
|---|---|---|
| 多折线图 | 多个指标随时间变化 | 各产业碳排放量趋势、多模型 CSI 对比 |
| 双轴柱线组合图 | 绝对值 + 增长率同时展示 | 碳排放量柱 + 同比增长率线（D 题标配） |
| 面积图 | 累积/构成随时间 | 碳排放达峰期/平台期/下降期示意 |
| 拟合曲线图 | 真实散点 + 模型曲线 | 水肿体积随时间拟合、Z-R 关系拟合 |

- **D23100060041**：图 4-1 2010-2020 各产业碳排放折线图（5 条线）；图 4-2 碳排放变化趋势及增长率（柱+线双轴）；图 5-3 灰色预测三线（真实/拟合/预测）。
- **D23104860011**：图 5-2 2010-2020 碳排放量 6 条折线（红/黄/绿/青/蓝/紫）。

## 2.1 多折线图

### 样式参数
- 主色板（matplotlib tab10）：`#1f77b4` 蓝、`#ff7f0e` 橙、`#2ca02c` 绿、`#d62728` 红、`#9467bd` 紫、`#8c564b` 棕
- 线宽 1.8~2.0
- 数据点 marker：`o`（圆）、`s`（方块），markersize=5
- 图例：右上或底部，frameon=False
- x 轴：年份/时间步，刻度整数

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

years = np.arange(2010, 2021)
rng = np.random.default_rng(0)
series = {
    '第一产业': 120 + 8*np.sin(years) + rng.normal(0, 3, len(years)),
    '第二产业': 500 + 30*(years-2010) + rng.normal(0, 8, len(years)),
    '第三产业': 200 + 25*(years-2010) + rng.normal(0, 6, len(years)),
}
colors = {'第一产业': '#1f77b4', '第二产业': '#d62728', '第三产业': '#2ca02c'}

fig, ax = plt.subplots(figsize=(8, 4.8))
for name, y in series.items():
    ax.plot(years, y, marker='o', linewidth=1.8, markersize=5,
            color=colors[name], label=name)
ax.set_xlabel('年份')
ax.set_ylabel('碳排放量（万 tCO$_2$）')
ax.set_title('2010-2020 年各产业碳排放量变化趋势', fontsize=12)
ax.legend(frameon=False, ncol=3, loc='upper left')
ax.set_xticks(years)
plt.tight_layout()
plt.savefig('/tmp/02_line_multi.png', dpi=300, bbox_inches='tight')
print('saved /tmp/02_line_multi.png')
```

### 常见坑
- 线条 >5 条时用不同 marker 区分，避免色盲读者混淆。
- x 轴年份必须整数刻度，不要自动生成小数。
- 图例放图外底部 `bbox_to_anchor=(0.5,-0.12), loc='center'`，避免压线。

## 2.2 双轴柱线组合图（左柱右线）

### 样式参数
- 柱色：`#C00000`（红）或 `#4472C4`（蓝），alpha=0.7
- 线色：`#1f77b4`（蓝）或 `#ED7D31`（橙），linewidth=2, marker='o'
- 左轴：绝对值（万 tCO$_2$），右轴：增长率（%）
- 两轴刻度颜色与对应柱/线一致

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

years = np.arange(2010, 2021)
total = np.array([520, 545, 560, 590, 610, 635, 650, 660, 655, 640, 620])
growth = np.diff(total) / total[:-1] * 100
growth = np.concatenate([[np.nan], growth])

fig, ax1 = plt.subplots(figsize=(8, 4.8))
bar = ax1.bar(years, total, color='#C00000', alpha=0.7, label='碳排放总量')
ax1.set_xlabel('年份')
ax1.set_ylabel('碳排放总量（万 tCO$_2$）', color='#C00000')
ax1.tick_params(axis='y', labelcolor='#C00000')

ax2 = ax1.twinx()
line = ax2.plot(years, growth, color='#1f77b4', marker='o', linewidth=2,
                label='同比增长率')
ax2.set_ylabel('同比增长率（%）', color='#1f77b4')
ax2.tick_params(axis='y', labelcolor='#1f77b4')
ax2.axhline(0, color='#999999', linewidth=0.8, linestyle='--')

# 合并图例
lines = [bar] + line
labels = [l.get_label() for l in lines]
ax1.legend(lines, labels, frameon=False, loc='upper left')
ax1.set_title('碳排放总量与同比增长率（双轴图）', fontsize=12)
ax1.set_xticks(years)
plt.tight_layout()
plt.savefig('/tmp/02_dual_axis.png', dpi=300, bbox_inches='tight')
print('saved /tmp/02_dual_axis.png')
```

### 常见坑
- 双轴图最忌左右轴量纲混淆，务必把轴标签颜色和刻度颜色对应。
- 右轴加 `axhline(0)` 零线，正负增长一目了然。
- 柱宽 0.6，避免柱太粗显得拥挤。

## 2.3 面积图

### 样式参数
- 灰色填充 `#7F7F7F` alpha=0.4（达峰示意）
- 或多色堆叠面积：`#4472C4`、`#ED7D31`、`#A9D18E`、`#FFC000`

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

x = np.linspace(2020, 2060, 200)
# 模拟碳排放曲线：上升→平台→下降
y = 1000 * np.exp(-((x-2035)/12)**2) * 0.0 + 1000/(1+np.exp(-(x-2030)/3)) - 800/(1+np.exp(-(x-2050)/3))

fig, ax = plt.subplots(figsize=(8, 4.5))
ax.fill_between(x, y, color='#7F7F7F', alpha=0.4)
ax.plot(x, y, color='#333333', linewidth=2)
# 标注阶段
ax.axvspan(2020, 2030, alpha=0.08, color='green')
ax.axvspan(2030, 2040, alpha=0.08, color='orange')
ax.axvspan(2040, 2060, alpha=0.08, color='red')
ax.text(2025, ax.get_ylim()[1]*0.9, '达峰期', ha='center', fontsize=10)
ax.text(2035, ax.get_ylim()[1]*0.9, '平台期', ha='center', fontsize=10)
ax.text(2050, ax.get_ylim()[1]*0.9, '下降期/中和期', ha='center', fontsize=10)
ax.set_xlabel('年份')
ax.set_ylabel('碳排放量（万 tCO$_2$）')
ax.set_title('双碳目标碳排放路径示意', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/02_area.png', dpi=300, bbox_inches='tight')
```

## 2.4 拟合曲线图（散点 + 模型曲线）

### 样式参数
- 散点：蓝色圆点 `#1f77b4`，s=18, alpha=0.7
- 拟合曲线：红色实线 `#C00000` 或橙棕 `#d95f0e`，linewidth=2.2
- 多项式拟合用 `np.polyfit`；高斯/核函数在图题标注 R²
- 双子图对比：左"未对数"右"对数时间"（E 题常用）

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

rng = np.random.default_rng(5)
t = np.sort(rng.uniform(0, 168, 80))                 # 时间（小时）
y = 5 + 0.08*t - 0.0012*t**2 + rng.normal(0, 1.5, len(t))  # 水肿体积

# 三阶多项式拟合
coef = np.polyfit(t, y, 3)
xs = np.linspace(0, 168, 200)
ys = np.polyval(coef, xs)
# R²
yhat = np.polyval(coef, t)
r2 = 1 - np.sum((y-yhat)**2)/np.sum((y-y.mean())**2)

fig, ax = plt.subplots(figsize=(7.5, 4.8))
ax.scatter(t, y, color='#1f77b4', s=18, alpha=0.7, label='观测散点')
ax.plot(xs, ys, color='#C00000', linewidth=2.2, label=f'三阶多项式拟合 (R²={r2:.3f})')
ax.set_xlabel('发病至影像时间（小时）')
ax.set_ylabel('水肿体积（ml）')
ax.set_title('水肿体积随时间三阶多项式拟合', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/02_fit.png', dpi=300, bbox_inches='tight')
print('saved /tmp/02_fit.png')
```

### 常见坑
- 散点用 `scatter` 不是 `plot`，否则每个点都连线。
- 图题或图例里必须标注模型阶数和 R²，否则读者不知道你拟合了什么。
- 多模型对比时用左右双子图（左模型 A 右模型 B），不要一张图叠 3 条以上曲线。

### 避坑总建议
- 折线图线宽统一 1.8~2.0，太细打印发虚，太粗显笨重。
- 双轴图是论文加分项，但每篇最多 2~3 张，别泛滥。
- 拟合曲线散点密度适中，>200 个点时改用小圆圈 s=12。
