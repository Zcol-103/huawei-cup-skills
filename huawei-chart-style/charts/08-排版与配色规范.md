# 08 排版与配色规范

> 这是华为杯优秀论文出图的统一规范。所有图在 matplotlib 顶部先设置这套 rcParams，再画图。

## 1. 全局 rcParams 模板（直接复制）

```python
import matplotlib as mpl
import matplotlib.pyplot as plt

# 中文字体：Windows 优先 SimHei；Linux/Mac 用 Noto Sans CJK SC / WenQuanYi Micro Hei
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False        # 负号正常显示
mpl.rcParams['font.size'] = 11                     # 全局字号
mpl.rcParams['axes.titlesize'] = 12                # 图题
mpl.rcParams['axes.labelsize'] = 11                # 轴标签
mpl.rcParams['xtick.labelsize'] = 10
mpl.rcParams['ytick.labelsize'] = 10
mpl.rcParams['legend.fontsize'] = 10
mpl.rcParams['axes.edgecolor'] = '#333333'          # 坐标轴颜色
mpl.rcParams['axes.linewidth'] = 0.8
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'
mpl.rcParams['grid.linewidth'] = 0.6
mpl.rcParams['grid.linestyle'] = '-'
mpl.rcParams['figure.dpi'] = 100
mpl.rcParams['savefig.dpi'] = 300                   # 导出 300 DPI
```

### 已验证可运行（全局样式自检）

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 11
mpl.rcParams['axes.grid'] = True
mpl.rcParams['grid.color'] = '#DDDDDD'

x = np.linspace(0, 10, 100)
fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(x, np.sin(x), color='#1f77b4', linewidth=2, label='正弦')
ax.plot(x, np.cos(x), color='#C00000', linewidth=2, label='余弦')
ax.set_xlabel('时间（秒）')
ax.set_ylabel('幅值（V）')
ax.set_title('全局样式自检图', fontsize=12)
ax.legend(frameon=False)
plt.tight_layout()
plt.savefig('/tmp/08_global_style.png', dpi=300, bbox_inches='tight')
print('saved /tmp/08_global_style.png')
```

## 2. 字体规范

| 场景 | 字体 | 字号 | 备注 |
|---|---|---|---|
| 论文正文中文 | 宋体（SimSun / Noto Serif CJK SC） | 小四 | 这是 Word 排版，不是 matplotlib |
| 图内中文标注 | 黑体（SimHei / Noto Sans CJK SC） | 10~11 | matplotlib 里用 |
| 图内英文/变量 | Times New Roman | 10~11 | 公式变量斜体 |
| 图题 | 黑体居中 | 12 | 置于图下方 |
| 坐标轴刻度 | 常规 | 10 | |
| 图例 | 常规 | 10 | |
| 三线表内文 | 宋体 | 五号 | |

> 实测：Linux 环境没有 SimHei，但有 `Noto Sans CJK SC` 和 `Noto Serif CJK SC`。rcParams 里列多个备选即可自动 fallback。

## 3. 字号经验值

- 单图（figsize 7×4.5）：轴标签 11，刻度 10，图例 10。
- 双子图并排（figsize 14×4.5）：每个子图轴标签 10，刻度 9。
- 2×2 子图（figsize 8×7）：轴标签 10，刻度 9。
- 3D 图：labelpad=8，避免标签被遮挡。
- 热力图单元格标注：8~9，矩阵 >10 个变量时关闭标注。

## 4. DPI 与导出

```python
plt.savefig('/tmp/xxx.png', dpi=300, bbox_inches='tight', facecolor='white')
```

- **dpi=300**：论文印刷分辨率，低于 200 打印发虚。
- **bbox_inches='tight'**：自动裁剪空白，避免标签被切。
- **facecolor='white'**：默认透明底，插入 Word 时可能变灰，强制白底。
- 格式：优先 PNG（位图）；流程图用 SVG/EMF（矢量）。

## 6. 图例位置规范

| 情况 | loc | 说明 |
|---|---|---|
| 数据不占右上 | `upper right` | 默认 |
| 数据占满 | `upper left` / `lower right` | 避让 |
| 序列多（>4） | `loc='upper center', bbox_to_anchor=(0.5, -0.12), ncol=3` | 放图底部 |
| 双子图 | 每个子图独立图例，或总图例放图外 | |
| frameon=False | 去掉边框 | 更干净 |

## 7. 中文标注规范

- 坐标轴标签必须带单位：`'碳排放量（万 tCO$_2$）'`、`'时间（小时）'`、`'水肿体积（ml）'`。
- 单位用全角括号（）包裹，数值与单位间半角空格。
- 下标/上标用 LaTeX：`'CO$_2$'`、`'R$^2$=0.92'`、`'C$_i$'`。
- 图内小标签可英文（变量名），但轴标题必须中文。
- 图题格式：`'图 5-3 各产业碳排放量变化趋势'`（居中置于图下方，黑体）。

## 8. 子图布局规范

| 布局 | figsize | 适用 |
|---|---|---|
| 单图 | (7, 4.5) | 默认 |
| 1×2 并排 | (13, 4.5) | 对比 a/b（如对数 vs 未对数） |
| 1×3 并排 | (17, 4.5) | 三类亚组对比 |
| 2×2 | (8, 7) | 四方案/四时序 |
| 2×3 | (11, 7) | 六子图（如 D 组 5-6 环比同比） |
| 10 帧条带 | (16, 3.2) | 雷达回波序列 |

- 子图间用 `plt.tight_layout()` 或 `fig.tight_layout()`。
- 共享坐标轴：`sharex=True, sharey=True`。
- 子图标签 (a)(b)(c)：`ax.set_title('(a) 方案一', fontsize=10)`。

## 9. 与三线表配合

- 图表序号连续编号：图 5-1、图 5-2…；表 5-1、表 5-2…。
- 图题在图下方，表题在表上方。
- 三线表格式：
  ```
  ━━━━━━━━━━━━━━━━━━━━━
    指标      |  值
  ─────────────────────
    ACC       |  0.92
    F1        |  0.89
  ━━━━━━━━━━━━━━━━━━━━━
  ```
- 不要画竖线和内部横线（除三线表那三条）。

## 10. 常见坑清单

1. **中文乱码**：忘设 `font.sans-serif` 或 `axes.unicode_minus=False` → 方块/负号变方块。
2. **标签被裁**：忘 `bbox_inches='tight'`。
3. **DPI 太低**：默认 100，插入 Word 打印模糊 → 必须 300。
4. **网格太粗**：grid.color 用 `#DDDDDD`，linewidth 0.6，别用默认黑灰。
5. **图例压线**：序列多时放图外底部。
6. **颜色过多**：一张图 >6 个序列时换用子图，别在一张图里堆 10 条线。
7. **3D 图点过密**：>1000 点改色阶散点或采样。
8. **饼图类别过多**：>6 类合并为"其他"。
9. **双轴图量纲混淆**：左右轴刻度颜色与对应柱/线一致。
10. **流程图用 matplotlib 硬画**：改用 Visio/draw.io/PPT，节省 80% 时间。
