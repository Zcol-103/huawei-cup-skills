# 05 空间与流类图表

> 用途：地理空间分布、雷达回波/降水场、来源-去向流量、节点网络关系。
> 论文中典型出现：雷达回波 ZH 场、中国地热气泡地图、碳排放流向、因果网络、GNN 图结构。

## 典型用途说明

| 图种 | 适用场景 | 论文中的典型问题 |
|---|---|---|
| 空间热力图/imshow | 二维场数据（雷达回波、降水分布） | NJU-CPOL 雷达 ZH 场、QPE 降水分布 |
| 气泡地图 | 地理点位 + 大小/颜色 | 全国各省竞赛参与度、碳排放 |
| 桑基图 | 来源→中间→去向流量 | 能源流向、产业碳排放转移 |
| 网络图 | 节点+边关系 | 因果贝叶斯网络、GNN 图结构 |

## 5.1 空间热力图（imshow，雷达回波/二维场）

### 样式参数
- 两派色板选其一：
  - `jet`：深蓝 #00007F → 蓝 #0000FF → 青 #00FFFF → 黄 #FFFF00 → 红 #FF0000（F 组部分论文）
  - `viridis`：深紫 #440154 → 蓝 #3B528B → 青 #21918C → 绿 #5EC962 → 黄 #FDE725（更现代，推荐）
- 插值：bilinear 或 nearest
- colorbar：右侧，label 为物理量（dBZ / mm/h）
- 多帧对比：1×N 横向条带或 2×N 网格
- 雷达范围外背景：纯黑

### 已验证可运行（单帧 + viridis）

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10

# 生成模拟雷达回波场（两个高斯团）
rng = np.random.default_rng(2)
x = np.linspace(-50, 50, 200)
y = np.linspace(-50, 50, 200)
X, Y = np.meshgrid(x, y)
Z = (35*np.exp(-((X-15)**2+(Y-10)**2)/400)
     + 25*np.exp(-((X+20)**2+(Y+15)**2)/600)
     + rng.normal(0, 1, X.shape))
# 范围外设为 NaN（纯黑背景）
Z[X**2+Y**2 > 2500] = np.nan

fig, ax = plt.subplots(figsize=(7, 6))
im = ax.imshow(Z, extent=[-50, 50, -50, 50], origin='lower',
               cmap='viridis', vmin=0, vmax=45, interpolation='bilinear')
ax.set_xlabel('东西向距离（km）')
ax.set_ylabel('南北向距离（km）')
ax.set_title('模拟雷达反射率因子 ZH 场', fontsize=12)
plt.colorbar(im, ax=ax, shrink=0.8, label='ZH（dBZ）')
plt.tight_layout()
plt.savefig('/tmp/05_radar_viridis.png', dpi=300, bbox_inches='tight')
print('saved /tmp/05_radar_viridis.png')
```

### 已验证可运行（10 帧条带对比，F 组典型）

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 9

rng = np.random.default_rng(6)
# 生成 5 帧随时间移动的回波
fig, axes = plt.subplots(1, 5, figsize=(16, 3.2))
xx, yy = np.meshgrid(np.linspace(-30, 30, 100), np.linspace(-30, 30, 100))
for i, ax in enumerate(axes):
    cx = -20 + i*8
    Z = 40*np.exp(-((xx-cx)**2+(yy)**2)/200) + rng.normal(0, 1.5, xx.shape)
    Z[xx**2+yy**2 > 900] = np.nan
    im = ax.imshow(Z, extent=[-30, 30, -30, 30], origin='lower',
                   cmap='jet', vmin=0, vmax=45)
    ax.set_title(f't+{i*10} min', fontsize=10)
    ax.set_xticks([]); ax.set_yticks([])
fig.suptitle('雷达回波临近预报序列对比', fontsize=12, y=1.05)
plt.colorbar(im, ax=axes, shrink=0.7, label='ZH（dBZ）')
plt.savefig('/tmp/05_radar_strip.png', dpi=300, bbox_inches='tight')
print('saved /tmp/05_radar_strip.png')
```

### 常见坑
- 多帧对比必须共享 colorbar（同一个 vmin/vmax），否则帧间不可比。
- 雷达范围外设 NaN 让背景纯黑，比矩形场更真实。
- 学术上 viridis 比 jet 更色盲友好，但 F 组老论文用 jet 也不少；模仿哪一派看你的论文风格。

## 5.2 气泡地图（地理点位）

### 样式参数
- 需要 geopandas / contextily 底图（本模板简化为散点模拟，实际用真实经纬度）
- 气泡大小映射数值，颜色映射类别
- 推荐 `#C00000` 红色气泡，alpha=0.5

### 已验证可运行（模拟中国区域气泡）

```python
# -*- coding: utf-8 -*-
import numpy as np
import matplotlib.pyplot as plt
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 10

# 模拟若干城市经纬度 + 参赛队数
rng = np.random.default_rng(10)
lons = rng.uniform(100, 125, 20)
lats = rng.uniform(25, 45, 20)
sizes = rng.uniform(50, 800, 20)
colors = rng.uniform(0, 1, 20)

fig, ax = plt.subplots(figsize=(8, 6))
sc = ax.scatter(lons, lats, s=sizes, c=colors, cmap='YlOrRd', alpha=0.6,
                edgecolors='#C00000', linewidths=0.5)
ax.set_xlabel('经度（°E）')
ax.set_ylabel('纬度（°N）')
ax.set_title('全国各省高校参赛队数气泡图（示意）', fontsize=12)
plt.colorbar(sc, ax=ax, shrink=0.8, label='参赛队数（示意）')
plt.tight_layout()
plt.savefig('/tmp/05_bubble_map.png', dpi=300, bbox_inches='tight')
print('saved /tmp/05_bubble_map.png')
```

### 常见坑
- 真正画中国地图需要 geopandas + 省界 shapefile；本模板仅模拟散点布局。
- 气泡大小用面积（s 参数）而非半径，避免视觉夸大。

## 5.3 桑基图

### 样式参数
- matplotlib 原生不支持桑基图，推荐 `plotly` 或 `matplotlib.sankey.Sankey`
- 流量条带颜色：来源端 `#4472C4`，去向端 `#ED7D31`
- 标签为节点名，字号 9

### 已验证可运行（matplotlib Sankey 基础版）

```python
# -*- coding: utf-8 -*-
import matplotlib.pyplot as plt
from matplotlib.sankey import Sankey
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 9

fig = plt.figure(figsize=(9, 5))
ax = fig.add_subplot(1, 1, 1, xticks=[], yticks=[])
# 流量：正值流入，负值流出
Sankey(ax=ax,
       flows=[0.6, 0.3, 0.1, -0.5, -0.4, -0.1],
       labels=['煤炭', '石油', '天然气', '工业', '电力', '居民生活'],
       orientations=[0, 1, -1, 0, 1, -1],
       ).finish()
ax.set_title('一次能源流向桑基图（示意）', fontsize=12)
plt.tight_layout()
plt.savefig('/tmp/05_sankey.png', dpi=300, bbox_inches='tight')
print('saved /tmp/05_sankey.png')
```

### 常见坑
- matplotlib Sankey 适合单节点分流；多节点复杂流向推荐 plotly。
- flows 之和必须约等于 0（流入=流出）。

## 5.4 网络图（节点+边）

### 样式参数
- 用 networkx
- 节点按类型着色：橙 `#ED7D31`、绿 `#70AD47`、灰 `#7F7F7F`、蓝 `#4472C4`
- 边：灰色 `#999999`，alpha=0.6
- 节点大小按度数

### 已验证可运行

```python
# -*- coding: utf-8 -*-
import matplotlib.pyplot as plt
import networkx as nx
import matplotlib as mpl
mpl.rcParams['font.sans-serif'] = ['SimHei', 'Noto Sans CJK SC', 'WenQuanYi Micro Hei', 'DejaVu Sans']
mpl.rcParams['axes.unicode_minus'] = False
mpl.rcParams['font.size'] = 9

G = nx.DiGraph()
edges = [('GDP', '能源消耗'), ('能源消耗', '碳排放'),
         ('人口', '能源消耗'), ('人口', '碳排放'),
         ('GDP', '碳排放'), ('技术进步', '能源消耗')]
G.add_edges_from(edges)
node_colors = {'GDP': '#ED7D31', '人口': '#70AD47', '技术进步': '#9467BD',
               '能源消耗': '#4472C4', '碳排放': '#C00000'}
colors = [node_colors[n] for n in G.nodes]

fig, ax = plt.subplots(figsize=(7, 5))
pos = nx.spring_layout(G, seed=3)
nx.draw_networkx_nodes(G, pos, node_color=colors, node_size=1200, alpha=0.85, ax=ax)
nx.draw_networkx_edges(G, pos, edge_color='#999999', arrows=True,
                        arrowsize=15, width=1.2, ax=ax)
nx.draw_networkx_labels(G, pos, font_size=10, ax=ax)
ax.set_title('碳排放影响因素因果网络示意', fontsize=12)
ax.axis('off')
plt.tight_layout()
plt.savefig('/tmp/05_network.png', dpi=300, bbox_inches='tight')
print('saved /tmp/05_network.png')
```

### 避坑总建议
- 空间热力图两派色板（jet / viridis）选其一并全篇统一，别混用。
- 多帧对比必须共享 colorbar。
- 网络图节点 >20 个时用力导向布局并关闭坐标轴。
